**Orbit 1.3.0 beta 3: no key needed to start.**

This is a beta. A beta install updates to later betas and to the next stable release.

- **Open and go.** Orbit opens straight to Qubit, on the Claude voice: it runs on your own Claude Code sign-in, so there's no key to enter. "Hey Orbit" and the hotkey work without one too.
- **Grok voice is optional.** Add an [xAI API key](https://console.x.ai) any time in Settings → Voice engine → Grok. If you pick Grok without a key, Orbit tells you and offers to switch back to Claude.
- **Picking Qubit up is sturdier.** He stays clickable and throwable even after sitting quietly for a long time.

Everything from beta 2 is here too: Orbit working in any window, Orbit's mouse, throwing Qubit, the new launcher, a choice of brain and speech-to-text model, the voice volume slider and more. See the [beta 2 notes](https://github.com/Cookiebubba/orbit-voice/releases/tag/v1.3.0-beta.2) and [CHANGELOG.md](../../blob/main/CHANGELOG.md).

You need Windows 10/11, the Claude desktop app and Claude Code. Grok voice is billed by xAI per minute while connected; the wake word costs nothing.

**Install:** download `Orbit-Setup-1.3.0-beta.3.exe` below and run it. The installer isn't code-signed yet, so on the SmartScreen prompt click **More info → Run anyway**. You can verify it with the `.sha256` file.

The latest stable release is [1.2.0](https://github.com/Cookiebubba/orbit-voice/releases/tag/v1.2.0). Not affiliated with xAI or Anthropic.
