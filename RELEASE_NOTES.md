**Orbit 1.0.0: talk to Claude Code Desktop with Grok Voice.**

- Ask what Claude is doing, hear when it finishes, switch sessions, and dictate prompts. Grok only sends after you say yes or click Send.
- Minimizes to a small always-on-top orb. The default hotkey is **Ctrl+Alt+G** (changeable in Settings).
- You need Windows 10/11, the Claude desktop app, and an [xAI API key](https://console.x.ai). Voice is billed by xAI per minute.

**Install:** download `Orbit-Setup-1.0.0.exe` below and run it. The installer isn't code-signed yet, so on the SmartScreen prompt click **More info → Run anyway**. You can verify it with the `.sha256` file.

Security: every finding from a full review was fixed before release. See [SECURITY.md](../../blob/main/SECURITY.md).
